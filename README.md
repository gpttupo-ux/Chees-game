# Шахи

Класичні шахи у браузері: гра проти комп'ютера або вдвох на одному екрані.

## Як запустити

Просто відкрийте `index.html` у браузері — жодного сервера чи збірки не потрібно.

## Можливості

- повні правила: рокіровка, взяття на проході, перетворення пішака;
- визначення шаху, мату, пату, триразового повторення, правила 50 ходів і недостатнього матеріалу;
- комп'ютерний суперник із трьома рівнями складності (пошук із альфа-бета відсіканням);
- режим гри для двох гравців;
- підсвічування доступних ходів, останнього ходу та шаху;
- список ходів у нотації SAN, експорт партії в PGN;
- скасування ходу, перевертання дошки, звуки;
- автоматичне збереження партії в `localStorage` (можна закрити вкладку й продовжити).

## Структура

```
index.html      розмітка інтерфейсу
styles.css      оформлення
js/engine.js    правила шахів (генерація ходів, статус партії, SAN)
js/ai.js        оцінка позиції та пошук найкращого ходу
js/app.js       інтерфейс, взаємодія, збереження
```
